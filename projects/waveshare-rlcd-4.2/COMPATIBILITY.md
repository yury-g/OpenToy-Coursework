# RLCD compatibility and test matrix

Assessment: 2026-11-17; catalog reviewed through OpenToy main `fd90e20` (README-only sourcing update `09281db` retained during publication). Original behavior source baseline `484a2fd` remains unchanged. This is a capability assessment; unported projects have not been compiled for RLCD. Every row needs its own versioned target build. The shared ESP32-S3 does not make existing firmware interchangeable.

| App / source | Required capabilities and RLCD adaptation | RLCD build / installed | Live / owner observation | Remaining checks |
| --- | --- | --- | --- | --- |
| Eyes 1 — [current OpenToy behavior](../animatronic-eyes/README.md) at `484a2fd` | Reuse Companion/Idle/Reaction and large pupils; monochrome 400x300, buttons replace pokes, fixed landscape | 0.2.0 source `aab1bba` built and installed | Native black-background renderer, all menu paths, synthetic reactions, freshness/performance/reboot checks pass / owner confirms version and cleaner appearance | Physical KEY/menu operation, detailed readability; battery presence and independent voltage/current verification |

All external branch heads must be freshly pinned when their port starts; this table does not pretend their latest code was audited or built. Archived Face v1/v2 source history is represented by active Eyes1/Eyes2 above, not new duplicate apps.

The [Orange Face faceplate](../3d-printed-designs/orange-face/README.md), Nearby Buddy enclosure and archived mechanical projects are mechanical designs, not firmware. None has RLCD physical-fit validation. Use the actual QC revision and measured dimensions before adapting a case; Waveshare V1/V2 spacers differ.

First Eyes release deliberately leaves audio, microphones, Wi-Fi, BLE, RTC and environmental sensing unused. I2C acknowledgments can establish responding peripherals but do not prove sensor accuracy, sound output or touch capabilities. See [verification](VERIFICATION.md) for actual evidence.

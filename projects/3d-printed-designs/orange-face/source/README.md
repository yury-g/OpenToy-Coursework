# Orange Face design source

[Visual project guide](../README.md) · [Print files](../print/) · [Build notes](../BUILD-NOTES.md)

These builders reproduce the November 16, 2026 button-access revision. The four
main views, CAD and slice were updated together. The existing clip-removal view
is retained because its section geometry is unchanged.

| File | Purpose |
| --- | --- |
| [design.py](design.py) | FreeCAD solid, board placement, cable routing, spring contacts and collision checks. Writes CAD to `../cad/`, STL to `../print/` and teaching geometry to `assembly.json`. |
| [Feather-Switches.FCStd](Feather-Switches.FCStd) | All five switch assemblies extracted from Adafruit’s STEP, replacing the old placeholder blocks. |
| [feather-switches.json](feather-switches.json) | Source URL, original STEP checksum, object names and materials. |
| [button-checks.json](button-checks.json) | Actual centers, actuator recess and cover access checks. |
| [hookup.py](hookup.py) | Vendor-derived board and cable geometry helpers. |
| [Reference-Boards.FCStd](Reference-Boards.FCStd) | Preserved reference assembly; the builder reads its Feather and touch geometry. Its older enclosure is reference history, not the current print. |
| [reference-materials.json](reference-materials.json) | Board part names and materials matching the reference assembly. |
| [render.py](render.py) | Builds four native Blender scenes from `assembly.json`; writes the scene file to `../blender/` and renders to `../images/`. |
| [render_clips.py](render_clips.py) | Builds the existing hold/release teaching view from `clip-cutaway.json`. Deflection is illustrative, not a structural simulation. |
| [checks.json](checks.json) | Recorded geometric checks from the delivered design. |

## Rebuild the CAD

Run these Python lines in FreeCAD's console or `freecadcmd --console`, starting
from the repository root:

```python
from pathlib import Path
import sys, runpy
source = Path("projects/3d-printed-designs/orange-face/source").resolve()
sys.path.insert(0, str(source))
result = runpy.run_path(str(source / "design.py"), run_name="__main__")
```

FreeCAD supplies `FreeCAD`, `Part`, `Import` and `MeshPart`. Change the dimensions
in `design.py` to make a new fit iteration. The existing document's spreadsheet
is a dimension record, not a live feature tree. The builder overwrites generated
CAD/STL files, so preserve a checkpoint before changing dimensions.

## Rebuild the teaching views

From the repository root, with Blender available on your command path:

```sh
blender --background --python projects/3d-printed-designs/orange-face/source/render.py
blender --background --python projects/3d-printed-designs/orange-face/source/render_clips.py
```

These commands overwrite generated images and Blender files. `assembly.json` is
regenerated by the CAD builder; `clip-cutaway.json` records the delivered clip
section and must be regenerated if its geometry changes. Fonts and their licenses
are included. The recorded renders used Blender 5.1.1.

## After a design change

Recheck solid validity, connected watertight mesh, board/component clearances,
intentional spring contacts, insertion/removal and cable bounds. Re-slice with
the intended machine, nozzle, material and plate. Existing G-code, validation
records and checksums do not update when the builder runs. Physical fit and
retention must be tested on real boards and a printed part.

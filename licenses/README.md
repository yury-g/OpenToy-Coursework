The full installed distribution license is preserved in [Pillow-12.3.0-LICENSE.txt](Pillow-12.3.0-LICENSE.txt), including its bundled component notices. Source: [python-pillow/Pillow](https://github.com/python-pillow/Pillow).

The exporter and generated OpenToy illustrations are original MIT-licensed project material. Existing firmware, Arduino/SDK and Python application dependency notices remain in their established per-project license directories and notices files. No Pillow binary or font package is bundled here; captions use Pillow's provided default font.

# Historical image archive

Preserved workspace images include intermediate firmware versions, deliberate offline states, and software framebuffers captured during debugging. They are not all final physical-screen verification. In particular `v15-purple-first.png` is the CYD software framebuffer before correcting its dual-USB ST7789 panel driver; the LCD was still black then.

Use `../screenshots/` for the final current family captures and `../renders/` for the final illustrated boards. The user-provided Feather demo reference is historical reference material, not a photograph of the final hardware family. Third-party references retain their original rights; project MIT terms cover the original source/art, not unrelated manufacturer images.
